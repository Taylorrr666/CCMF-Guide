Compulsory Module

Quantitative Methods

Explore how quantitative methods can be used to answer cause-and-effect questions, analyse data and support evidence-based decision-making.

Course Overview

Quantitative Methods focuses on how data can be used to answer cause-and-effect questions in economics and business. The module introduces disciplined approaches to causal inference, beginning with the problem of selection bias and moving through experimental and quasi-experimental methods. Key methods include randomized controlled trials, regression, instrumental variables, regression discontinuity and difference-in-difference.

Learning Outcomes

The module develops the ability to approach empirical questions using structured quantitative reasoning.

01

Ask Causal Questions

Frame economic and business problems in terms of cause and effect.

02

Use Data Systematically

Evaluate causal questions using evidence rather than intuition alone.

03

Understand Selection Bias

Recognise why simple comparisons may fail to identify causal effects.

04

Apply Causal Methods

Understand how RCTs, regression, instrumental variables, regression discontinuity and difference-in-difference can be used for causal inference.

05

Interpret Empirical Results

Assess the assumptions, strengths and limitations behind quantitative estimates.

Core Methods

The course progresses from experimental identification to observational and quasi-experimental approaches.

Randomized Controlled Trials

Use random assignment to create comparable treatment and control groups and estimate causal effects.

Regression

Use regression models to control for observed variables and analyse relationships in observational data.

Instrumental Variables

Use external sources of variation to address endogeneity and omitted variable bias.

Regression Discontinuity

Identify causal effects around a treatment cutoff using a running variable.

Difference-in-Difference

Compare changes over time between treatment and control groups.

Causal Inference

Evaluate whether observed relationships represent true causal effects rather than selection or confounding.

Causal Analysis Workflow

A useful way to understand the module is as a progression from a causal question to a credible empirical estimate.

1

Question

Define the causal relationship you want to understand.

2

Counterfactual

Identify the outcome that would occur without treatment.

3

Bias

Consider selection bias and omitted variables.

4

Identification

Choose an appropriate causal inference method.

5

Interpretation

Interpret the estimate and assess its assumptions.
