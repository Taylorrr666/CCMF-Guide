Compulsory Module

Quantitative Methods

Learn how data, econometrics and causal inference can be used to test hypotheses, evaluate evidence and support business decision-making.

Course Overview

Quantitative Methods introduces some of the most important data analysis tools used in economics and business. The module combines an understanding of the theory behind quantitative methods with their practical application to real data. Key areas include econometrics, regression analysis, causal inference and machine learning. The overall objective is to move from a hypothesis, to data analysis, to evidence-based conclusions.

Learning Outcomes

By the end of the module, students should be able to apply quantitative methods to practical economics and business problems.

01

Analyse Data

Select graphical and analytical techniques to present data and identify important trends.

02

Use Statistical Tools

Apply statistical software to conduct quantitative analysis and support business decision-making.

03

Understand Causal Inference

Explain and apply basic concepts used to identify causal relationships.

04

Interpret Regression Models

Understand regression output and interpret estimated relationships in an applied context.

05

Manage Data Resources

Assemble, collect and manage large data resources for quantitative analysis.

Core Methods

The module introduces quantitative tools for identifying patterns in data, estimating relationships and evaluating causal effects.

Econometrics

Use statistical methods to analyse economic and business data.

Regression Analysis

Estimate relationships between variables and interpret regression coefficients and model results.

Causal Inference

Distinguish correlation from causation and evaluate whether observed outcomes can be attributed to an intervention.

Experimental Methods

Understand how experimental designs can be used to estimate causal effects.

Data Analysis

Organise, visualise and interpret data to identify meaningful patterns.

Machine Learning

Explore data-driven approaches used for prediction and analytical modelling.

Quantitative Analysis Workflow

A useful way to understand the module is as a sequence from research question to evidence-based conclusion.

1

Hypothesis

Define the question or relationship to test.

2

Data

Collect and organise relevant evidence.

3

Method

Select an appropriate quantitative technique.

4

Analysis

Estimate, test and interpret the results.

5

Conclusion

Evaluate whether the evidence supports the original hypothesis.
